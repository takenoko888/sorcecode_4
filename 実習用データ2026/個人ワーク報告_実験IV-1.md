# 電子情報通信実験IV-1 個人ワーク報告

## 1. 目的
practice01_09.csv と practice01_08.csv を用いて、以下を実施した。

1. 線形回帰式の推定
2. 基底展開（多項式）回帰におけるモデル次数（パラメータ数）の AIC 最小化選択
3. 回帰結果を散布図（2D/3D）に重ねて比較

## 2. 使用データ（実行したデータの内訳）
- 実行ノートブック: example01_01.ipynb（単回帰）, example01_02.ipynb（重回帰）
- 単回帰で実行したデータ: practice01_09.csv
- 使用列: 1列目（エネルギー E [eV]）と 2列目（(αE)^2_室温 [(eV/cm)^2]）
- 使用点数: 104 点（全行を使用）
- 重回帰で実行したデータ: practice01_08.csv
- 使用列: 1列目（圧力 x2 [Torr]）, 2列目以降のヘッダ（放電電流 x1 [mA]）, 表内部（目的変数 y = 電圧 V [V]）
- 使用点数: x1 が 18 点, x2 が 9 点, y は 9 x 18 = 162 点
- 補足: practice01_09.csv の 100℃, 150℃, 200℃ の列は今回の単回帰実行には使用していない

## 3. 回帰分析法とモデル設定
### 3.1 単回帰（practice01_09）
- モデル1: 線形単回帰
- モデル2: 多項式単回帰
- 多項式次数候補: p = 1, 2, ..., 30
- モデル選択基準: AIC

AIC は以下で評価した。

AIC = n log(2π MSE) + n + 2(k + 1)

ここで n はサンプル数、k は回帰係数数（切片を除く）。

### 3.2 重回帰（practice01_08）
- モデル1: 線形重回帰
- モデル2: 多項式基底展開重回帰
- 多項式次数候補: p = 1, 2, ..., 50
- パラメータ数: (p+1)(p+2)/2
- モデル選択基準: AIC

## 6. 考察（主観）
- practice01_09 では線形単回帰は立ち上がり領域の非線形性を十分に表現できず、AIC による次数選択を適用した多項式回帰（p=19）が形状追従性の面で優位だった。
- practice01_08 では線形重回帰より基底展開重回帰（p=5, m=21）が適合度とモデル複雑度のバランス（AIC）で良好だった。
- ただし高次数化は過学習リスクを伴うため、AIC による複雑度ペナルティを含む選択は妥当である。
